# 🔗 Linktree Maia

## 📌 Apresentação do Projeto

O Linktree Maia é uma página personalizada desenvolvida para reunir os principais links de redes sociais, contatos e plataformas em um único local. O projeto possui uma interface limpa, moderna e totalmente responsiva, permitindo que visitantes acessem rapidamente todas as informações importantes através de uma única página.

Seu design minimalista proporciona uma navegação simples e agradável em qualquer dispositivo.

---

## ✨ Funcionalidades

- ✔️ Exibição da foto de perfil
- ✔️ Lista personalizada de links
- ✔️ Botões interativos
- ✔️ Interface moderna
- ✔️ Layout totalmente responsivo
- ✔️ Navegação simples e intuitiva

## 📂 Estrutura do Projeto

```text
liktree-maia/
│
├── css/
│   ├── style.css
│   └── responsivo.css
│

│
└── index.html
```

### Estrutura

**css/**
- Contém os arquivos responsáveis pela estilização e adaptação para dispositivos móveis.

**src/**
- Armazena a imagem de perfil e demais recursos visuais da aplicação.

**index.html**
- Estrutura principal da página de links.
